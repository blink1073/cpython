:mod:`smtplib`: when the server advertises the ``SMTPUTF8`` extension
(:rfc:`6531`), :meth:`~smtplib.SMTP.auth` now encodes authentication
responses as UTF-8, enabling Unicode usernames and passwords for
``AUTH PLAIN`` (:rfc:`4616`) and ``AUTH LOGIN``.  ``AUTH PLAIN``
additionally escapes embedded ``NUL`` characters (``\x00``) as ``%x00``
to preserve SASL PLAIN field framing.  ``AUTH CRAM-MD5`` requires ASCII
credentials per :rfc:`2195`; non-ASCII credentials raise
:exc:`UnicodeEncodeError`.  Without ``SMTPUTF8``, all mechanisms use ASCII
encoding.  Unicode credential handling is also tested in :mod:`imaplib`
(via ``ENABLE UTF8=ACCEPT``) and :mod:`ftplib`.
